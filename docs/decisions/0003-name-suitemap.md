# 0003: Name the project "Suitemap"

- Status: accepted
- Date: 2026-11-27

## Context

The working name "Testmap" was already taken on npm. Candidates were checked against the npm registry and for existing testing products.

## Decision

Use **Suitemap**: npm `suitemap` (CLI) and the `@suitemap` scope for packages.

## Consequences

- "Suite" + "map" says what the tool produces and leaves room for non-test adapters (API specs, Storybook) later.
- Reserve `suitemap` and the `@suitemap` npm organisation before Phase 1.
